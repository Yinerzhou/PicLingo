# PicLingo 1.2.0 使用说明

## 安装与启动

Windows 双击 `PicLingo-Setup-1.2.0.exe`，选择安装位置，保留“桌面快捷方式”选项，完成后从桌面图标启动。安装包内置两个处理引擎和中英离线模型。

Windows 安装包当前未使用商业代码签名证书。若 SmartScreen 显示未知发布者，请先核对本次交付的 SHA256，确认文件来源后按系统提供的“更多信息 → 仍要运行”继续。公司策略阻止安装时，由公司管理员处理。

Mac 按处理器选择对应安装包，Apple Silicon 包面向 M 系列芯片，Intel 包面向 Intel Mac。最低系统按构建配置为 macOS 13。打开 DMG，将 PicLingo 拖到 Applications，再从 Applications 启动。当前 Developer ID 签名与 Apple 公证状态见验证报告。

首次使用 PSD 模块前，请安装并启动 Photoshop 2024，完成登录及首次运行设置。

## 图片翻译

侧边栏“图片翻译”继续提供批量导入、OCR、离线翻译、译文校对和导出。中英模型随安装包提供，其他目标语言可在“离线语言包”中下载。

白色蒙层默认 94%。在“设置”中仍可在原有 70%～94% 范围内手动调整。系统透明材质受操作系统的透明效果及辅助功能设置影响，不支持时沿用兼容背景。

## PSD 出图

1. 点击侧边栏“PSD 出图”，选择一个或多个 PSD，也可拖入 PSD 文件。
2. 导入 XLSX，存在多个工作表时选择对应工作表。
3. 选择按英文原文、按图层 Key 或手动指定，再点击“读取匹配”。
4. 检查匹配状态、各语言译文、图层信息与多余词条。
5. 勾选输出语言，选择 PNG、JPG 或 PSD，设置命名规则和保存位置。
6. 点击“开始导出”，完成后查看失败项和字体/溢出警告，点击“打开目录”查看结果。

该模式直接使用 Excel 译文，读取 Photoshop 的可编辑文字图层。译文不会由机器翻译生成。

## Excel 格式

| Key | en | de | fr | ja |
|---|---|---|---|---|
| headline | Summer Sale | Sommeraktion | Soldes d’été | サマーセール |
| discount | Save up to 50% | Bis zu 50% sparen | Jusqu’à 50 % de réduction | 最大50%オフ |
| button | Shop Now | Jetzt einkaufen | Acheter | 今すぐ購入 |

语言列兼容 `en / EN / English / 英文` 等别名。默认按英文原文匹配，可将图层名称设为 Key 并切换对应匹配方式。首列为英文原文的表格也可以导入。

重复 Key 或原文使用第一条并警告。空译文与未匹配图层保留原文。公式及错误值需要先粘贴为纯文本。

## 字体与排版

- 默认跳过隐藏图层，可在输出设置中选择处理隐藏文字，图层可见性按原 PSD 保留。
- 缺失原字体时跳过该图层，并在报告中记录字体名。
- 原字体缺少目标语言字形时，按语言尝试已安装的备用字体。可展开“字体设置”修改备用字体的 PostScript 名。
- 无法确认字形覆盖且没有合适备用字体时，保留原文并记录原因。
- 默认仅提示“可能溢出”。选择“缩小字号”后会尝试缩到原文字区域或段落框内，达到字号下限后仍存在风险的项目继续提示。
- 复杂混合样式按相对字符区间映射，原字体、字号、颜色及对齐信息由 Photoshop 保留。跨语言重点词的位置需要人工检查。
- 内嵌 PSD/PSB 智能对象可以递归处理，链接对象及其他格式对象会记录为未处理。
- 阿拉伯语、希伯来语需勾选“RTL 实验”。方向、连字、标点、数字及客户字体仍需样张验收。

原始 PSD 会校验哈希。已有未保存修改的输入 PSD 会提示先保存或关闭。处理在内存副本中完成，输出文件重名时自动增加序号。

## 报告与日志

导出目录包含图片/PSD 及 `出图报告_任务编号.json`，其中记录成功、失败、文字替换、字体回退、未处理对象与溢出检查结果。

“PSD 出图 → 查看日志”可打开任务目录。“设置 → 导出日志”与 PSD 页面的“导出日志”可导出 ZIP，包含图片翻译错误日志、PSD 日志及环境信息。

Windows 默认日志目录位于 `%APPDATA%\piclingo-system-glass\psd`，图片翻译错误日志位于其上级的 `worker.log`。macOS 默认位于 `~/Library/Application Support/piclingo-system-glass/psd`。开发版或测试版可使用独立数据目录，页面“查看日志”对应当前实际目录。

超时后先检查 Photoshop 是否仍在执行、是否有对话框。日志中的 `RECOVERY_REQUIRED.json` 会阻止继续发起不确定的任务。按开发与发布说明中的恢复步骤处理，避免重复调用。

## 更新

设置中可配置 GitHub 仓库并启用启动时检查。发现新版本后，“下载安装”会下载对应平台安装包并核对 SHA256，再打开安装程序。

当前更新器使用可匿名访问的 GitHub Releases。私有构建仓库的访问权限与客户端更新源需要分别配置，当前发布源状态见验证报告。
