## 在线升级实测

1. 在独立安装目录安装包含自动更新功能的 1.3.1，使用独立用户数据目录。

3. 通过发布签名与 SHA512 校验，弹出更新日志和“重启更新”选项。
4. 点击“重启更新”，静默安装真实 NSIS 包，重新启动至 1.3.2。
5. 检查独立测试中的个人文件与用户数据保留，运行升级后真实图片翻译、译文修改和导出流程，均通过。

首次验证的 1.3.1 没有公开发行 blockmap，更新器按预期回退为完整后台下载。1.3.2 已公开 blockmap，供后续版本进行差分下载。

## 自动更新行为

启动后延迟 30 秒检查，之后每 4 小时检查一次。新版后台下载并显示进度与日志。下载完成后可以重启更新，或设置下次启动时更新。安装前再次检查当前出图任务、文件摘要与发布签名。错误写入日志。

空更新地址会使用内置公开源，用户填写的有效地址和关闭自动检查的选择会保留。

## 后续发布与平台限制

后续版本需要增加版本号，构建并签名更新清单，发布到同一仓库的正式 Release，客户端即可自动检测。

Windows 使用内置公钥验证更新发布签名，安装包仍未配置商业代码签名，首次手动下载安装时可能显示 SmartScreen 提示。

Mac 正式自动安装仍需要 Developer ID 签名与公证配置。Mac Photoshop、Photoshop 2024 及客户复杂 PSD 的验收继续按原计划在目标设备进行。

使用 GitHub Actions 全自动构建发布时，仓库管理员需要配置 `PICLINGO_UPDATE_PRIVATE_KEY` Secret。本轮发行通过本机构建和签名后上传完成，签名私钥保存在本机用户私有目录。
